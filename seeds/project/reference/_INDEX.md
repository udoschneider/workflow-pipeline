# Reference Index

Topic-based reference docs for this project. Each entry summarizes what the doc covers and when to consult it — in enough detail that the agent can rule a doc *out* without opening it, which is the whole reason this index exists.

Maintained by `/prune-lessons`, which promotes clusters of related lessons out of `project/lessons.md` into a synthesized reference doc here and adds its entry in the same pass. **No orphan references:** a doc without an entry is invisible, and an entry without a doc is a dangling pointer.

This file starts empty. It fills as lessons accumulate and cluster — a reference doc extracted before there is anything to synthesize is just a lesson with more ceremony.

## Entry format

```markdown
## filename.md

**Topic:** <one-line topic>
**Covers:** <2-3 lines on scope — what's inside, what decisions or patterns are captured>
**Consult when:** <the situation where the agent should reach for it>
```
