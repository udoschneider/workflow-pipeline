# Lessons Learned

> Orphan entries that didn't cluster into a dedicated reference doc. Each of these either stands alone, or is waiting for companion lessons to justify extraction. Once a group of lessons shares a topic, promote them into a reference doc and leave a pointer here.

Run `/prune-lessons` periodically to triage entries into references, code comments, or the bin.

Entries are grouped under a topic heading (`## Development Environment`, `## Testing`, …) and each lesson is an `###` heading phrased as the takeaway, not the symptom:

### A one-line title stating the rule, not the incident

The body explains what happened, why the obvious reading was wrong, and what to do instead. Keep the concrete detail — the specific error text, the exact command — because that is what makes the lesson findable later.
